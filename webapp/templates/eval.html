How this works, and what it's measured at

The reference page: the check modes, the methodology, and the evaluation numbers behind the "1 reader" / "Reader panel" buttons on Run a document.

Check modes

1 reader The single simulated reader used in the locked evaluation. 2 model calls, about 15–30s.
Reader panel Five simulated readers, defined by how they read, not who they are: the skimmer, limited health literacy, English as an additional language, an older adult on several medicines, an anxious reader. Flags if any reader misreads. 10 model calls in parallel, about 30–60s.

This evaluation uses a small test set (n=8 primary + 4 extended edge cases), not a population-level validation. The readability baseline flags every document in the set identically, real or planted — it cannot tell a dangerous reversed instruction from a clean one, because reversing meaning barely changes syllable count. Four additional hand-built edge cases, including one fully documented failure case, are reported separately in EVAL_RESULTS.md rather than folded into these headline numbers. See the README's "Honest limits" section for what's still needed before this could be trusted on a real patient.
